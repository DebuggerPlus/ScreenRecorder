rnnoise models for the arnndn filter
====================================

bd.rnnn — "beguiling-drafter-2018-08-30" from https://github.com/GregorR/rnnoise-models
Trained for: a voice recording with general (non-speech) background noise — a fan,
air conditioning, room tone. This is the default model of the Process Video window.

Other models from the same repository can be dropped next to this file and selected
in the window (the model file box). The repository states that the model data itself
is not a creative work and is not subject to copyright.
