# ScreenRecorder: audio pack

Пакет для репозитория https://github.com/DebuggerPlus/ScreenRecorder (ветка master, база — коммит ca40d07).

## Что внутри
- `HERMES_INSTRUCTIONS.md` — инструкция для агента Hermes, который собирает проект: что применить, как собрать, что проверить, критерии приёмки.
- `files/` — новые и изменённые файлы целиком, пути как в репозитории.
- `changes.patch` — то же самое одним патчем (`git apply changes.patch`).

## Что добавлено
- Окно **Audio Settings** (кнопка в боковой панели и на Home): выбор источника, режим захвата WASAPI (event/polling/exclusive), размер буфера, запрос формата драйвера, выходная частота / разрядность / каналы, усиление, фильтр НЧ, дизеринг, битрейт AAC.
- **Эквалайзер**: 10 полос, 6 пресетов.
- **Тест и диагностика**: запись только звука без видео, raw-копия потока устройства, индикаторы уровня и статистика потерь, повторная обработка raw-файла с текущими настройками, конвертация в FLAC/MP3/M4A, анализатор щелчков/провалов/клиппинга для любого файла (можно сравнить с записью Bandicam).
- Поток захвата звука разгружен: запись на диск, ресемплинг и фильтры вынесены в отдельный поток, повышен приоритет потока захвата, пониженный приоритет ffmpeg.
- Вкладка **Recordings**: выбор папки по умолчанию, проверка доступа, открыть папку, сброс.
- Самотест `tools/AudioChainSelfTest`.

## Статус проверки
Core и аудиокод Infrastructure скомпилированы, самотест (30 проверок) проходит. WPF-часть (`ScreenRecorder.App`) не компилировалась, работа с реальными устройствами (iVCam, Bluetooth-гарнитура) не проверялась: это задача Hermes и ручной проверки на Windows. Подробности — в `HERMES_INSTRUCTIONS.md`, раздел 2.
